# Archery-master Neon Sight UI リデザイン仕様

日付: 2026-06-22  
対象: Web/PWA (`index.html` と既存の UI レイヤ)  
選択案: 2番「Neon Sight」

## 目的

練習中に片手で迷わず記録を始められることを最優先にし、現行の機能と端末内データを保ったまま、画面全体を近未来的なネオンUIへ刷新する。説明のための文章や未検証の訴求を減らし、操作・現在条件・結果を主役にする。

## 守るもの

- 得点記録、着弾入力、分析、履歴、統計、用具、バックアップの既存機能
- `db`、localStorage、復元用スナップショットなど既存の保存形式
- 5タブ構成と主要な画面遷移
- データ消失、練習用機能、分析の不確実性に関する必要な警告
- scoring、physics、storage の計算・保存ロジック

## ビジュアル方針

黒に近いグラファイトを基調に、ティールの発光線と小さな琥珀色の照準点を使う。ネオンは面を塗る装飾ではなく、選択状態、主要操作、現在位置を示すために使う。

- 背景: `#05090B` を中心とした黒紺
- 主アクセント: 冷たいティール / シアン
- 副アクセント: 照準点だけに使う琥珀色
- 文字: 高コントラストの白と、補助情報用の青灰色
- 形状: 円形サイトレティクル、細い区切り線、広い余白
- カード: 必要なまとまりだけに限定し、カードの入れ子を作らない
- 数字: 距離、的サイズ、得点を等幅に近い字形で強調する

ライトテーマ選択は残すが、このリデザインの標準表示はダークとする。

## ホーム

最初の画面には次の順で表示する。

1. 小さなブランド名と設定ボタン
2. 「今日の練習」
3. `70m / 122cm / 用具未指定` のような現在条件
4. サイトレティクルと一体化した大きな「記録を始める」操作
5. 最近の記録。未記録時は「まだ記録はありません」の一行だけ
6. 5タブの固定ナビゲーション

既存の週間サマリーは折りたたみの二次情報として残す。「前回と同じ」「履歴」などの補助操作は、主要CTAを邪魔しない位置へ移す。

## 共通画面

- 記録: 的と現在エンドを最優先にし、操作中の状態だけを発光させる
- 分析: 説明用ヒーローを廃止し、結果、必要本数、次の操作を短く表示する
- 履歴: セッションを一つのリスト面にまとめ、日付、距離、得点を速く読めるようにする
- 統計: グラフと数値を主役にし、見出し以外の説明文を極力置かない
- 設定: 現行の階層とデータ安全警告を保ち、ネオンは選択状態のみに使う
- モーダル/シート: 黒い面、上端の細いティール線、十分なタップ領域で統一する

## 文章整理

ユーザー操作に必要なラベル、実データから算出される値、安全警告だけを残す。機能紹介、将来を想起させる表現、効果を保証する表現は削除する。

主な対象:

- `index.html` の description / OGP
- ホームの空状態と補助文
- 記録開始画面の訴求文
- 履歴、用具、サイト調整のヒーロー文章
- manifest の description

「サイト調整の提案」のように実装済みでも誤解が生じやすい機能は、入力データ不足時の条件と不確実性を同じ場所に表示する。端末保存、バックアップ、削除、練習用機能の注意書きは削らない。

## モーション

- ホーム表示: レティクルが短く収束して停止
- 記録開始: ティールの輪郭が一度だけ光り、押下時に小さく縮む
- タブ切替: 選択アイコン下を短い光線が移動
- 得点確定: 既存の pop を色と速度だけ統一
- シート表示: 既存 spring を短く保つ
- 常時動く粒子、強い点滅、大きなパララックスは使わない
- `prefers-reduced-motion: reduce` では装飾アニメーションを停止する

## PWAアイコン

Neon Sight と同じ視覚言語で、新しい正方形アイコンを作る。

- 黒紺の背景
- ティールの円形サイトレティクル
- 中心に小さな琥珀色の照準点
- 文字、細かい目盛り、写真表現は使わない
- iOSの角丸マスクでも主要図形が欠けない安全域を確保する
- 1024pxのマスターから PWA 用 PNG と `apple-touch-icon.png` を生成する
- manifest、favicon、起動画面、ヘッダー参照を新しい画像へ揃える

## 実装境界

UIの変更は既存の `html.ui-refresh` レイヤを中心に行い、CSSトークン、画面用CSS、モーションCSS、必要最小限のテンプレート文言を更新する。得点計算、分析計算、保存形式には手を入れない。

ホームのレティクルは装飾専用要素とし、「記録を始める」ボタンのクリック処理は既存の `quickStartSession` を使う。表示条件は既存の距離、的、用具データから作り、新しい状態や保存項目を追加しない。

## エラーと空状態

- 読み込み失敗: 再読み込み操作と端末保存の説明を残す
- 記録なし: 一行の状態と記録開始CTAを表示
- 分析材料なし: 必要本数と次に行う操作だけを表示
- 用具未指定: 条件行に事実として表示し、登録を強制しない
- オフライン: 既存PWA動作を保ち、見た目の変更でキャッシュ対象を欠落させない

## 検証

- `npm run check:app`
- `npm run check:ui`
- `npm run check:ui-layer`
- 390 x 844 でホーム、記録、分析、履歴、統計、設定を確認
- デスクトップ幅で崩れ、文字切れ、カード入れ子、操作不能がないことを確認
- 記録開始、条件変更、タブ切替、設定表示、バックアップ導線を操作確認
- reduced motion で装飾アニメーションが止まることを確認
- iOSホーム画面用アイコンを180px表示で確認

## リリース

実装後に `npm run version:bump -- 76` 相当の既存バージョン更新を行い、`APP_VER`、`version.json`、service worker cache、package metadata を v76 に揃える。対象ファイルだけをコミットし、ユーザーの未追跡ファイルは含めない。`main` を GitHub に push し、GitHub Pages の `version.json` と公開画面が v76へ更新されたことを確認する。
